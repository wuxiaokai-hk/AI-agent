Reading Map: From Generative AI to AI Agents

An AI agent today is a language model placed in a loop: it reasons, calls a tool, reads the result, and repeats until the task is done. Each part of that came from a different line of research. Click any paper for its problem, key idea, the formulas explained in words, a worked example you can follow by hand, and a question to check yourself. Papers marked ▶ have interactive sliders. ★ marks the 12 core papers. As of November 2026.

Suggested order for you

Start at the practical end, since you are already building agents. Read Building Effective Agents and ReAct first, then Lilian Weng's overview post. Go back to the foundations (Transformer, scaling laws, GPT-3, InstructGPT, chain of thought). Finish with DeepSeek-R1, METR's time horizons, and the economics section.
